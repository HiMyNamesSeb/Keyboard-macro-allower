## ℹ️ Overview

I love coding, but the worst part about it is practicing in an IDE where you just look at print statements. I wanted to make a tool I would ACTUALLY use, 
and so I created this. I often play repetitive games, and so this tool would allow me to record inputs and then replay them, allowing me to gain rewards
and skip the tedious work while I do something else.

## 🚀 Usage

Use the UI to select start recording. End recording with the stop recording button or "[" by default. PLay back once, or loop the playback. Press "]" to end the playback early
